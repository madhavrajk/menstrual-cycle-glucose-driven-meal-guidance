# knowledge/ (Step 3, Sneha)

Curated inputs for grounded meal guidance. These are not participant data, so they're safe to commit.

- `recipes/`: about 50 recipes. Ingredients in grams with FoodData Central IDs, dietary-pattern
  tags, allergens, cooking time, and meal type.
- `evidence_cards/`: claim, food or dose, population studied, source, strength, cautions.
